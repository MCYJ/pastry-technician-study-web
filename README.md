# 제과기능사 · Pastry Technician Study

RushLabs의 제과기능사 독립 학습 앱을 소개하는 출시 준비 사이트입니다. 한국어 학습 콘텐츠를 준비하며, 웹 안내는 한국어·영어로 제공합니다. 앱 다운로드나 구매는 아직 제공하지 않습니다.

## Build

Node.js 24에서 의존성 설치 없이 실행합니다.

```sh
PUBLIC_SITE_URL=https://mcyj.github.io/pastry-technician-study-web npm run build
npm run check
npm run preview
```

GitHub Actions가 정적 출력을 GitHub Pages에 배포합니다. 검색 색인은 아직 활성화하지 않았습니다.

[한국어 안내](https://mcyj.github.io/pastry-technician-study-web/ko/) · [English](https://mcyj.github.io/pastry-technician-study-web/en/)

시험 구성은 [Q-Net 제과기능사 안내](https://www.q-net.or.kr/crf005.do?id=crf00503s02&jmCd=7892&jmInfoDivCcd=B0)를 확인하세요. 독립 서비스이며 공식 운영기관의 인증·보증을 주장하지 않습니다.
